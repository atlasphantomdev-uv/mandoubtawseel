# مندوب توصيل في الإمارات | Mandoub Tawseel UAE

موقع **مندوب توصيل** و**مندوب التوصيل** في الإمارات — خدمة توصيل فوري وتوصيل نفس اليوم
في دبي، أبوظبي، الشارقة، عجمان، رأس الخيمة، الفجيرة، أم القيوين، والعين.

Arabic-first, SEO-driven landing site for a UAE courier/delivery business
(**مندوب توصيل** / **مندوب التوصيل**), built with Hugo + Hugo Blox and deployed to
GitHub Pages. Arabic owns the site root; English mirrors it under `/en/`.

---

## الكلمات المفتاحية المستهدفة | Target keywords

الموقع مبني على خريطة كلمات مفتاحية موثّقة ببيانات بحث حقيقية (Google Autocomplete
`hl=ar&gl=ae` ونتائج بحث فعلية)، وليس على تخمين.

| النوع | الكلمات | الصفحة المستهدفة |
|---|---|---|
| رئيسية | مندوب توصيل · مندوب التوصيل | `/` |
| تجارية | شركة توصيل · خدمة توصيل · أسعار مندوب التوصيل | `/اسعار-مندوب-التوصيل/` |
| المدن | مندوب توصيل في دبي · أبوظبي · الشارقة · عجمان · رأس الخيمة · الفجيرة · أم القيوين · العين | `/مندوب-توصيل-في-<المدينة>/` |
| الخطوط | مندوب توصيل من دبي للعين · دبي إلى أبوظبي · الشارقة إلى أبوظبي | `/خطوط-التوصيل/` |
| الخدمات | توصيل طلبات مطاعم · مستندات · سيارات · فوري · نفس اليوم · رخيص · تطبيق | `/خدمات/` |
| الوظائف | وظائف مندوب توصيل · انضم كمندوب | `/وظائف-مندوب-توصيل/` |
| معلوماتية | ما هو مندوب التوصيل · كيف أصبح مندوب توصيل | `/مدونة/` |

ملاحظة مهمة من تحليل المنافسين: الكلمة العامة **مندوب توصيل** محتلة من الجهات الحكومية
( mohre.gov.ae، tamm.abudhabi ) ومتاجر التطبيقات والعلامات الكبرى، وليس من شركات صغيرة.
لذلك يتركّز الموقع على **مندوب التوصيل** و**شركة توصيل** وكلمات المدن، وهي المساحة التي
تتصدر فيها شركات صغيرة فعلًا.

## بنية الموقع | Site architecture

```
/                                    الصفحة الرئيسية (ar-ae, RTL)
├── خدمات/                           7 صفحات خدمات + فهرس
├── مندوب-توصيل-في-<مدينة>/           8 صفحات مدن (مع aliases للهمزة)
├── خطوط-التوصيل/                     التوصيل بين الإمارات + 6 خطوط
├── اسعار-مندوب-التوصيل/              الأسعار
├── مناطق-التغطية/                    مناطق التغطية
├── وظائف-مندوب-توصيل/ + انضم-كمندوب/  الوظائف والتسجيل
├── مدونة/                            4 مقالات تعريفية
└── /en/                              النسخة الإنجليزية (hreflang reciprocity)
```

ترتيب الكتل في كل صفحة هبوط (لا يجوز وضع كتلتين داكنتين متجاورتين):

```
hero (غامق) → لوحة الحجز (فاتحة) → بطاقات الخدمات (فاتحة + accent للفوري ونفس اليوم)
→ الأسعار (فاتح + زر غامق) → الخطوات السبع (فاتح) → التقييمات (فاتح/رمادي)
→ خريطة الإمارات (فاتح) → الأسئلة الشائعة → CTA (غامق)
```

### التفاصيل التقنية

- **Grading/SEO**: `hreflang` متبادل + `x-default`، canonical ذاتي على كل صفحة،
  sitemap index متعدد اللغات، JSON-LD (`WebSite`، `LocalBusiness`، `Service`،
  `BreadcrumbList`، `FAQPage`، `BlogPosting`).
- **RTL**: `dir="rtl"` مدفوع من `data/i18n/rtl.yaml` عبر `site.Language.Locale`،
  وأدوات Tailwind منطقية (`ms-`/`me-`/`ps-`/`pe-`) بدل الفيزيائية.
- **الهمزة**: الكلمات مثل `أبوظبي`/`ابوظبي` و`رأس الخيمة`/`راس الخيمة` تُخدَم عبر
  `aliases` — لأن GitHub Pages لا تدعم إعادة التوجيه من الخادم. يبقى الـ canonical على
  الصيغة الأساسية فقط.
- **الخطوط العربية**: `removePathAccents: false` — إلزامي، وإلا يُحذف الهمزة من اسم
  الملف (`وظائف` ← `وظايف`) وتنكسر كل الروابط الداخلية.

## التشغيل محليًا | Local development

```bash
pnpm install        # تبعيات Tailwind CLI و Pagefind
pnpm dev            # hugo server --disableFastRender  → http://localhost:1313
pnpm build          # hugo --minify ثم فهرسة Pagefind
```

متطلبات: Hugo extended (0.168.0)، Node ≥ 20، pnpm 10.
يجب أن يكون Hugo **extended** لأن القالب يستخدم `css.TailwindCSS`.

## النشر | Deployment

النشر تلقائي إلى **GitHub Pages** عبر GitHub Actions:

- `.github/workflows/deploy.yml` — يقرأ `deploy.host` من `hugoblox.yaml`، يبني، يرفع، ثم ينشر.
- `.github/workflows/build.yml` — بناء قابل لإعادة الاستخدام (تحقق من الـ PR).
- `hugoblox.yaml` — `hugo_version` و`deploy.host: github-pages`.

**مطلوب مرة واحدة يدويًا:** إعدادات المستودع → Pages → Source = **GitHub Actions**.
بدون هذا لن يعمل النشر رغم أن البناء ينجح.

الرابط: `https://atlasphantomdev-uv.github.io/mandoubtawseel/`

## قبل الإطلاق | Before go-live

كل قيمة عمل حقيقية غير متوفرة موضوعة كـ placeholder قابل للبحث (`TODO_`).
استبدلها قبل النشر، ولا تُخترع أي قيمة:

| Placeholder | المطلوب |
|---|---|
| `TODO_BRAND` / `TODO_BRAND_AR` / `TODO_BRAND_EN` | اسم النشاط (عربي + إنجليزي) |
| `TODO_WHATSAPP` | رقم واتساب للـ CTA الأساسي (زر الحجز) |
| `TODO_PHONE` | رقم الهاتف |
| `TODO_FORM_ENDPOINT` | نقطة استقبال نموذج الحجز (Formspree أو مشابه) |
| `TODO_ADDRESS` / `TODO_OFFICE_HOURS` | العنوان وساعات العمل |
| `TODO_PRICE` | الأسعار (يُسمح بـ 15 درهم لأنها مُعلنة من صاحب النشاط) |
| `TODO_EARNINGS` | نموذج أرباح المناديب في صفحة الوظائف |
| `TODO_RATING` / `TODO_REVIEW_*` / `TODO_REVIEWER_*` / `TODO_ROLE_*` | التقييمات — **لا تُختلق آراء عملاء** |
| `TODO_TRANSIT_TIME` | مدد التوصيل بين المدن |

`TODO_*` ممنوعة داخل أي JSON-LD — يوجد تحقق آلي يمنع ذلك.

### تحقق

```bash
hugo --minify                      # يجب أن يخرج 0 مع صفر أخطاء
grep -r "TODO_" content | wc -l    # المتبقي من البيانات الناقصة
```
